# Analyse des données de criminalité à Chicago

> Big Data / Urban Analytics

## Vue d'ensemble

Projet d'analyse exploratoire des incidents criminels à Chicago. L'objectif est d'identifier des tendances temporelles, géographiques et typologiques pour mieux comprendre les zones et périodes à risque.

## Objectifs du projet

- Explorer un historique de criminalité volumineux.
- Identifier les catégories d’infractions les plus fréquentes.
- Mettre en évidence les tendances par période et par zone.
- Fournir une base analytique exploitable pour la priorisation opérationnelle.

## Démarche

- Chargement et préparation des données dans un notebook.
- Analyse des volumes par type de crime, date et zone.
- Visualisations pour rendre les tendances compréhensibles.
- Synthèse des observations sous forme de rapport.

## Stack technique
